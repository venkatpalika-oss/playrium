PLAYRIUM — COMPLETE 23-EXPERIENCE REVIEW

WINDOWS
1. Right-click the downloaded ZIP and choose Extract All.
2. Open the extracted folder. Do not open an HTML file inside the ZIP.
3. Double-click experiences.html to browse all 23 experiences.
4. Keep components/ and all other folders beside the HTML files.

This package contains the ten rebuilt games and the thirteen newly styled
experiences. It is a review build. It does not change the live website.

If a game appears as plain black text on white, its styles/scripts are missing:
extract the complete archive rather than copying one HTML file.

Chrome or Edge on a laptop is the easiest way to review the extracted files.
Scores stored locally may differ between file previews and the eventual website.
